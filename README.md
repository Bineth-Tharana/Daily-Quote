# Daily Quote App

A simple and responsive web application that displays inspiring quotes using a Quotes API. Users can generate a new quote with a single click and stay motivated throughout the day.

## 🚀 Live Features

* Fetches random quotes from an external Quotes API
* Displays quote text and author name
* Generate a new quote instantly
* Clean and responsive user interface
* Lightweight and easy to use
* Beginner-friendly JavaScript project

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Quotes API

## ⚙️ Installation

1. Clone the repository:

```bash
git clone https://github.com/Bineth-Tharana/Daily-Quote.git
```

2. Navigate to the project folder:

```bash
cd Daily-Quote
```

3. Open `index.html` in your browser.

## 🎯 How It Works

1. The application sends a request to a Quotes API.
2. A random quote is retrieved.
3. The quote and author are displayed on the screen.
4. Clicking the **New Quote** button fetches another quote instantly.
